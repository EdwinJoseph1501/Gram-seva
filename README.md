# 🌱 Gram Seva

### An Offline-First Grievance Portal for Rural Communities

Gram Seva is a lightweight, multilingual grievance portal designed to help rural citizens document and manage local community problems.

The application provides an accessible interface for recording grievances related to water supply, electricity, roads, sanitation, healthcare, and agriculture.

## ✨ Features

- 📝 **Complaint Management:** Submit, view, search, filter, update, and delete complaints.
- 📍 **Location Details:** Record state, district, block, village, and ward information.
- 🛰️ **GPS Support:** Capture geographical coordinates with user permission.
- 📷 **Photo Evidence:** Attach photographs with client-side image compression.
- 🌐 **Multilingual Interface:** Supports 10 Indian languages.
- 🌙 **Dark Mode:** Switch between light and dark themes.
- 📊 **Analytics Dashboard:** Visualize locally stored complaints by category and status.
- 💾 **Backup and Restore:** Export and import complaint records using JSON files.
- 📱 **Progressive Web App:** Supports installation on compatible browsers.
- 📶 **Offline Support:** Cache essential application resources for offline reopening.
